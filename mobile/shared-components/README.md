# Shared Mobile Components & Design Tokens

Cross-platform user experience components, typography assets, Ethiopic script font definitions, and shared networking/state contracts.

## Key Assets
- **Fonts**: Optimized Ethiopic typography (Abyssinica SIL, Noto Sans Ethiopic) and Latin typefaces.
- **UI Components**:
  - Two-way conversation split-screen layout (Signer View / Hearing View)
  - Confidence indicators and clarification action prompts
  - Few-shot gesture recording wizard
  - Avatar playback speed selector (0.5x, 0.75x, 1.0x, 1.25x)
