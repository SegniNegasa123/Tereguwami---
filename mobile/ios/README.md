# Native iOS Client

Native iOS implementation supporting real-time camera-based continuous translation and interactive generative avatar rendering.

## Architecture
- **Language**: Swift / SwiftUI
- **Inference Engine**: Apple Core ML / ONNX Runtime Mobile accelerated via Apple Neural Engine (ANE)
- **Vision Pipeline**: AVFoundation + Metal Performance Shaders
- **Avatar Render**: SceneKit / RealityKit real-time blendshape animation
