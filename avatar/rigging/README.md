# 3D Avatar Rigging & Anatomical Blendshapes

Skeletal hierarchy, finger articulation constraints, and facial action coding system (FACS) blendshape rigs designed specifically for Ethiopian Sign Language phonetic precision.

## Rigging Specifications
- **Upper Body Skeleton**: Full shoulder, elbow, wrist, and 15-joint multi-segment finger rig ensuring realistic manual handshapes without unnatural mesh clipping.
- **Facial Blendshapes (ARKit / FACS Standardized)**:
  - `browDownLeft` / `browDownRight` (wh-questions, intensity)
  - `browInnerUp` / `browOuterUpLeft` (yes/no questions)
  - `jawOpen`, `mouthPucker`, `mouthFunnel`, `cheekPuff` (ESL mouthings and lexical mouth gestures)
  - Head rotation matrix (yaw, pitch, roll) for linguistic nodding, shaking, and tilting.
