# Ethics, Privacy, and Community Governance

Documentation of ethical principles, community partnerships, and data privacy protocols governing the Tereguwami project.

## Core Governance Pillars

1. **Deaf-Led Governance Board**: A standing committee of Ethiopian Deaf community leaders, linguists, and educators holding decisive approval authority over data collection protocols, model evaluations, and research publications.
2. **Informed Consent & Enforceable Withdrawal**: Every contributing signer provides informed consent in Ethiopian Sign Language and retain the permanent right to withdraw their video footage from future benchmark releases.
3. **Privacy by Default**: Raw video footage is never stored on servers or committed to version control without explicit per-instance consent. Personalization runs on-device using federated learning.
4. **Scientific Honesty**: Explicit boundaries distinguishing neuromotor sEMG decoding from unsupported "mind-reading" claims.
5. **High-Stakes Verification**: Human-in-the-loop verification mode for clinical, judicial, and emergency communications.
