# Proposals & Research Concept Documents

This directory contains the formal and technical project proposals for **Tereguwami (ተርጓሚ)**.

## Document Inventory

- **Technical & Research Working Document (Document A)**: Complete 28-page internal engineering, research, and design reference document covering problem statements, Ethiopian & global literature review, 9-layer system architecture, feature catalogue, benchmark design, roadmap, team, and references.
- **Submission Proposal (Document B)**: Scoped proposal formatted for submission to institutional grant committees, academic partners (e.g. Addis Ababa University, international research labs), and government funding bodies.
