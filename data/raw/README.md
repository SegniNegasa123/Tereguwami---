# Raw Video Data (Consent-Gated & Access-Controlled)

> [!CAUTION]
> **DO NOT COMMIT RAW SIGNER FOOTAGE TO GIT OR PUBLIC STORAGE.**

This directory holds raw RGB video recordings captured during recording sessions with consented participants.
- Access is restricted exclusively to authorized researchers under approved institutional data-use agreements.
- All files are indexed with anonymized subject identifiers (e.g., `signer_042_session_01.mp4`).
- Signer consent documents are managed separately under `governance/consent-forms/`.
