# Real-Time Streaming Pipeline

Ultra-low-latency real-time bidirectional streaming infrastructure for continuous two-way conversation sessions.

## Protocol Stack
- **WebRTC**: Peer-to-peer and SFU video/audio streams for high-bandwidth real-time camera ingestion.
- **WebSockets**: Lightweight JSON/binary frames transmitting normalized keypoint packets, incremental partial translation hypotheses, confidence scores, and avatar blendshape animations.
- **Latency Target**: Sub-250ms end-to-end latency from signer motion completion to audio/text synthesis.
