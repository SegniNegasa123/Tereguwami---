# Authentication & Authorization Services

Security and identity infrastructure ensuring strict role-based access control (RBAC) and data isolation.

## Security Tiers
- `Anonymous / Guest`: Ephemeral sessions, on-device translation only, zero data persistence.
- `Registered Signer`: Encrypted personal profile, custom enrolled gesture vectors, federated update tokens.
- `Researcher / Annotator`: Consent-gated dataset access, evaluation suite submission tokens.
- `Deaf Advisory Board`: Administrative audit logs, dataset validation permissions, consent withdrawal triggers.
- `Institutional API Client`: Dedicated high-throughput keys for broadcasters, hospitals, and telecom relay systems.
