# FastAPI Backend Services

RESTful endpoints powering client applications, third-party integrations, institutional relays, and portal management.

## Endpoints Overview
- `/api/v1/translate`: Synchronous batch translation (video/keypoints to text/audio).
- `/api/v1/produce`: Reverse translation (text/audio to 3D avatar pose streams).
- `/api/v1/personalize`: Custom sign enrollment, exemplar upload, and few-shot vector storage.
- `/api/v1/health`: Cluster health, GPU inference metrics, and latency monitors.
