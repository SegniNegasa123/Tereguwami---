# Experiment Tracking & Configs

Tracked hyperparameter configurations, ablation study plans, and evaluation run records.

## Structure
- `configs/`: YAML configuration files specifying model architectures, learning rates, batch sizes, and data paths.
- `logs/`: WandB / TensorBoard run metadata and summary metric logs.
- `ablations/`: Ablation studies (e.g., hands-only vs. hands-plus-face non-manual markers).
