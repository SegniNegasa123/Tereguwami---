# Research & Exploratory Notebooks

This directory contains Jupyter notebooks used for experimental data exploration, landmark visualization, metric tracking, and baseline validations.

## Recommended Notebook Conventions
- `01_eda_signer_demographics.ipynb`: Demographic distributions, lighting variations, and duration statistics.
- `02_perception_mediapipe_pipeline.ipynb`: Landmark extraction inspection and validation on sample frames.
- `03_baseline_recognition_experiments.ipynb`: CNN-LSTM and BiLSTM model evaluation.
- `04_transformer_translation_evaluation.ipynb`: Gloss-free cross-lingual transformer training curves & BLEU-4 metrics.
- `05_semg_signal_processing.ipynb`: AlterEgo sEMG filtering, feature extraction, and classification.
